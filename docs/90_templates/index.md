# Templates

## Purpose

This section contains reusable document templates for project artifacts.

Templates provide starting structure and authoring guidance, but they are not
the controlled project baselines themselves.

## Current Coverage

- [Requirements](02_requirements/index.md) - requirement document templates.

## Usage

- Use templates as reference starting points when creating project artifacts.
- Apply project-specific content before baselining.
- Keep lifecycle process guidance in `docs/10_lifecycle/` and governance rules
  in `docs/00_governance/`.
